# Kashmir Decor — baseline audit & measurements (before changes)

Date: 2026-11-13 · Base commit: `0e841d3` (main) · Branch: `arena/b49143cd-kashmir-uz`

## Environment
- Sandbox has no reachable production database and no Vercel Telemetry access.
- A local PostgreSQL-compatible server (PGlite 0.5.16 / PostgreSQL 18.6 wire server,
  `127.0.0.1:5432`) was started so the **real** Drizzle schema, seed and queries run.
- App: `npm run build` + `npm run start` (Next 16.2.6), measured with HTTP keep-alive off,
  warm server, 15 iterations after 2 warm-up requests.
- Chromium cannot be downloaded in this sandbox (`playwright install` network failure), so
  browser-level LCP/INP/CLS *cannot* be measured here. All browser metrics below are marked
  unverified. Bundles and payloads are measured from the build output and response bodies.

## Root-cause findings (source-verified)

1. **Localization never consults the database.**
   `I18nProvider` holds locale in client state; `tc()/ti()/ts()` read a hardcoded dictionary
   keyed by product slug (`CURTAINS`/`INTERIORS`/`STATS` in `src/lib/i18n.ts`).
   `src/lib/data.ts` returns raw rows (`name`, `description`) with no locale awareness, so
   every visitor sees the single stored language. Admin edits can never reach another locale.
   FAQ is the only table with per-language columns and it falls back to English.

2. **Uploaded images are stored as base64 data URLs inside `curtains.image_url` /
   `interiors.image_url` / `gallery.image_url`** (`src/lib/image-processing.ts` →
   `data:image/webp;base64,…`, up to 3 MB each, and `gallery` is a JSONB array of them).
   `SELECT *` then inlines those bytes into the RSC payload/HTML of every page.
   With 4 products that is up to **12 MB of HTML**; the seed dataset (which uses `/assets/*`)
   produced only 53 KB — proving the cost is data-dependent and invisible in the repo.

3. **No caching layer at all.** Every public page is `force-dynamic`, `sitemap` is
   `revalidate = 0`, and every request re-runs 4–6 queries. A cold pool costs a TCP+TLS+auth
   handshake per connection (`max: 5`).

4. **Duplicated/over-broad queries.** The homepage fetches full `curtains` rows (including the
   `gallery` JSONB) for a grid that only needs name/image/likes. `getActiveCurtains()` is
   called by `/`, `/collections`, `/gallery`, `/sitemap.xml` with no shared caching.

5. **Website preview** — `AdminNav` renders `<Link href="/">`. In production this is a same-tab
   client navigation to the *current* origin (preview URL or localhost), and it drops the admin
   user out of the panel. There is no central site-URL config shared with `seo.ts`.

6. **Dead payload in the client bundle**: ~850 lines of translation dictionaries ship to every
   visitor, including RU/UZ/EN copies of product copy that belongs in the database.

7. `eslint .` fails with **10 errors** on `main` (react-hooks `setState` in effect,
   `next/no-html-link-for-pages`), so "lint passes" was not true before this work.
